# 你好，我是麻薯。

也可以叫我 **MaShu**。这里是我的个人技术与实践笔记，用来整理软件开发、工程实践和日常探索中遇到的问题，也给以后遇到相同问题的自己留一份参考。

把踩过的坑写下来，把解决过的问题整理清楚。下次再遇见，就有迹可循。内容从具体问题出发，主题随着实践逐步扩展。

- **数据库与基础设施**：数据存储、服务器环境和服务部署，已有 Redis、Nginx、Docker 的安装配置与使用记录。
- **开发环境与工具**：语言环境、版本管理和日常工具，已有 Java、Python 环境整理与使用笔记。
